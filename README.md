# 🧊 Punto Frío

> Proyecto web moderno construido con **Astro**, enfocado en rendimiento, simplicidad y una estructura limpia lista para producción.

---

## 🚀 Descripción

**Punto Frío** es un sitio web desarrollado con Astro que aprovecha la generación de sitios estáticos para ofrecer una experiencia rápida, optimizada y escalable. El proyecto está pensado como base sólida para un sitio informativo o corporativo, con componentes reutilizables y una arquitectura clara.

---

## 🛠️ Tecnologías utilizadas

- ⚡ **Astro**
- 🟨 **JavaScript / TypeScript**
- 🎨 **Tailwind CSS**
- 🧩 Componentes reutilizables
- ☁️ **Vercel** para despliegue

---

## 📁 Estructura del proyecto

/
├── public/ # Archivos públicos (imágenes, favicon, etc.)
├── src/
│ ├── pages/ # Páginas del sitio
│ ├── layouts/ # Layouts generales
│ └── components/ # Componentes reutilizables
├── supabase/ # Configuración y migraciones (si aplica)
├── package.json # Dependencias y scripts
├── astro.config.mjs # Configuración de Astro
├── tailwind.config.mjs # Configuración de Tailwind
└── tsconfig.json # Configuración de TypeScript


---

## ⚙️ Instalación y uso local

1. Clona el repositorio:
   ```bash
   git clone https://github.com/MalcomSandoval/Punto_frio.git
Entra al proyecto:

cd Punto_frio
Instala las dependencias:

npm install
Ejecuta el servidor de desarrollo:

npm run dev
Abre en el navegador:

http://localhost:4321
📦 Scripts disponibles
npm run dev → Servidor de desarrollo

npm run build → Build para producción

npm run preview → Vista previa del build

🌐 Despliegue
El proyecto está preparado para desplegarse fácilmente en Vercel conectando el repositorio y configurando las variables de entorno necesarias (si aplica).
